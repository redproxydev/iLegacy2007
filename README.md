# ⚡ iLegacy 2007

> *Resurrecting 2007 mobile tech in the browser. No cap.*

**iLegacy 2007** is an open-source, frontend-driven project dedicated to meticulously rebuilding and reimagining the legendary **iPhone OS 1** experience directly inside the modern web browser. 

No heavy emulators, no bloated frameworks. Just pure web craft capturing that classic skeuomorphic aesthetic, the OG *Slide to Unlock*, and the raw nostalgia that changed tech forever back in '07.

## 🛠️ What's this about?
* **🔥 Build in Public:** Tracking UI progress, design breakdowns, and core logic live.
* **📦 Open Source & Moddable:** Clean, modular structure designed not just for nostalgia, but as a sandbox for devs and enthusiasts to experiment, hack, and build custom tweaks.
* **✨ The Vibe:** High-impact web engineering. A fully accessible playground for anyone wanting to build mobile experiences without needing legacy hardware.
